# LANDY Creator — binding rules

<!-- gate-first-exempt: index file; declares no rule of its own -->

Thirteen rule files. Every one is written **gate-first**: What/Why + **FAIL
condition** + **WHERE-checked** + **Enforcement strength**.
`scripts/governance/validate-gate-first.sh` mechanically fails any that isn't.

## Creator money-path (new — authored for this product)

| Rule | Guards |
|---|---|
| `legal-advice-framing.md` | Every user-facing string is information, not advice (UPL). |
| `redact-before-inference.md` | No un-redacted PII reaches an LLM (UU PDP). |
| `extraction-coverage.md` | Non-empty text is not proof of successful extraction. |
| `tracked-changes-authenticity.md` | Real OOXML `w:ins`/`w:del`, never simulated formatting. |
| `tenant-isolation.md` | Explicit `WHERE user_id` is the isolation layer; RLS is second. |
| `secrets-hygiene.md` | Nothing secret and no user data enters git. The repo is public. |
| `unknown-state.md` | Every classification/parse step has a representable, rendered "we don't know" state (LC-41). **Proposed 2026-08-02 — binds after MV sign-off on the LC-41 PR.** |

## Carried from landy-workspace (adapted to Creator paths)

## Enforcement Registry

Single scannable table, generated by cross-reading every rule's own
WHERE-checked / Enforcement-strength lines (those lines remain the source of
truth; this table is a derived index for "which gate catches this?" at a
glance). `scripts/governance/validate-enforcement-registry.sh` fails the build
if a rule file has no row here, or if a `validate-*.sh` script exists with no
row referencing it — the drift guard that keeps this table honest.

| Trigger | Binding rule | Validator | Enforcement |
|---|---|---|---|
| Any user-facing AI output | `legal-advice-framing.md` | `validate-legal-advice-framing.sh` | mechanical + self-audit |
| Any `chat_complete()` call site | `redact-before-inference.md` | `validate-redaction-before-inference.sh` | mechanical + self-audit |
| Extraction path (`extraction.py` or successor) | `extraction-coverage.md` | `validate-extraction-coverage.sh` | mechanical |
| DOCX export / redline generation | `tracked-changes-authenticity.md` | `validate-tracked-changes.sh` | mechanical + self-audit |
| Any route touching tenant-owned data | `tenant-isolation.md` | `validate-tenant-isolation.sh` | mechanical + self-audit |
| Any commit / any tracked file | `secrets-hygiene.md` | `validate-secrets-hygiene.sh` | mechanical |
| Classification / parse step with a user-visible output | `unknown-state.md` (**Proposed** — binds after explicit MV sign-off, not implied by a merge) | `validate-silent-failure.sh` + `validate-silent-failure-web.sh` | mechanical + self-audit |
| Extraction / LLM / analysis failure path | `silent-failure.md` | `validate-silent-failure.sh` | mechanical + self-audit |
| Any write to `statutes.status` | `status-integrity.md` | `validate-status-integrity.sh` + `validate-provenance-schema.sh` | mechanical |
| Corpus schema / risk-flag citations | `provenance.md` | `validate-provenance-schema.sh` + `validate-legal-advice-framing.sh` | mechanical + self-audit |
| `statutes.tier_basis` / `citations.basis` | `statutory-vs-doctrinal.md` | `validate-hierarchy.sh` | mechanical + self-audit |
| Any fetch path against an external legal source (dormant) | `source-access.md` | `validate-source-access.sh` | mechanical + self-audit |
| Rule-file shape itself | *(this file — no product rule)* | `validate-gate-first.sh` | mechanical |
| `.agents/memory/*.md` orphan/link health | *(no product rule — hygiene)* | `validate-bridge-health.sh` | mechanical |
| `.agents/memory/*.md` staleness vs. passing gates | *(no product rule — hygiene)* | `validate-memory-sync.sh` | mechanical + self-audit |
| Registered `*-INDEX.md` heading maps (e.g. `CLAUDE-INDEX.md`) | *(no product rule — hygiene)* | `validate-index-sync.sh` (wraps `scripts/src/index-headings.ts --check`) | mechanical |
| Money-path commit (money-path file list per `silent-failure.md` + `unknown-state.md`) | `session-reconciliation.md` | `money-path-guard.sh` (PreToolUse hard-stop) | mechanical + self-audit |
| End of a turn where money-path files changed (session-close reminder) | `session-reconciliation.md` | `wrap-session-reminder.sh` (Stop hook, advisory-only) | mechanical (fires unconditionally) + self-audit (running `/wrap-session` in full is not itself gated) |

**Reading this table:** "mechanical" means a script's exit code is the verdict;
"self-audit" means the gate can only approximate the judgment and a human (or
`/review-gate`, `/export-gate`, `/wrap-session`) closes the gap. A row with only
"mechanical" is the rare case where the grep genuinely is the whole test
(`status-integrity.md`).
